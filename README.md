# 人生之书 · 卡牌小工具（life-deck）

把「人生建议」做成卡牌游戏：先选方向 → 踏上旅途 → 收集 10 张建议卡 → 出「旅途结算」，
告诉你照着做能避开哪些坑、拿到哪些收益，并生成一张 1080×1440 的小红书战报图。

- **在线玩**：https://hotcoffeeshake.github.io/life-deck/
- **仓库**：https://github.com/hotcoffeeshake/life-deck
- **小红书工具包（上传包）**：[Releases 下载](https://github.com/hotcoffeeshake/life-deck/releases/latest) ，
  或仓库内 `life-deck-xhs-package.zip`（入口 `index.html` 在 ZIP 根目录，包内仅 `index.html` + `assets/`，无任何外链，可离线）

全离线运行，数据只存在使用者这台设备。原文来自 HowToLiveBetter（Unlicense，快照 commit `8276caec`）。

## 已实现

- 七个人生阶段按钮（新增“正在找工作”），随后直接选择目标。关注方向决定排序，明确处境决定建议是否可自动推荐。
- 608 条原文按“8 个方面 → 40 个子主题 → 具体建议”建立路由，再标注可能更关注的人生阶段及适用情景。可审查表见 `design/建议路由表.md` 和 `design/建议路由明细.tsv`。
- 每个阶段有三个具体目标，前三组先围绕目标推荐；先过滤适用前提，再按目标、阶段及已选卡排序。看过三组才问是否看其他领域，候选不足时不拿无关卡凑数。目标和子主题权重见 `design/v7-目标路由表.tsv`。
- 608 条建议另有独立适用前提表，见 `design/建议适用前提.md` 和 `.tsv`。所有推荐、跟进、探索和兜底先检查前提；求职不会自动解锁工伤或网站运营。点击兴趣卡不反推用户处境，全库主动选择有条件的建议时先确认。
- 点击推荐卡即收进下方固定牌组，自动进入下一步；再点牌组中的卡，才展开完整原文。没有独立“加入 / 跳过 / 下一组”按钮。
- 都不想收时可向左划过整组；键盘聚焦卡组后可按左方向键。不操作则停留，不根据停留时间推断偏好。
- 卡面左上角用费用徽记展示原文金钱成本，顶部标时间与毅力，底部展示收益等级和收益口径。保留原文等级，不转换为虚构分数，不把不同收益口径相加。
- 看过 3 组后问“想看看其他领域的建议吗？”，可选“看看其他领域 / 继续这个方向 / 都可以”；选择继续时优先跟进当前方向，连续两次划过整组时允许调整方向；收满 10 张进入概览，可保存清单或从一条开始实施。
- 移除后可补齐，连点不重复收藏；本轮和已归档的牌组分别保留，v4/v5/v6 当前会话升级至 v7，保留收藏和估算，替换不符合已确认处境的旧推荐。v1–v3 历史收藏仍可读取。
- 一条原文对应一张牌；正文、引用和备注完整保留，阅读页不重复标题。原文元数据注释不混入正文，“说人话”字段名隐藏，字段内容不删减。
- 订阅与通信卡可填写个人数字估算；核对并计算后自动保存，无额外收藏步骤。完整阅读页导出 1080×1560 分页图片。
- 全离线，未上传发布。
- v8 旅途版（2026-09-27）：冒险者叙事包装——选人生阶段即"选方向"，收集页有旅途进度（10 步）；集满 10 张出"旅途结算"，按牌组统计照做能避开的坑（反面清单＋安全领域）、收益方向（金钱/时间/自由/健康）与用户已核对的估算金额，并可生成 1080×1440 小红书战报图。卡面加八大领域单字印章与主题色、子主题名；"口径"改称"收益形式"，"这是一条劝阻"改称"反面清单"；粗糙 CSS 小人换为线稿旅途徽章。

## 运行

使用已有 Python：`python3 -m http.server 8796 --bind 127.0.0.1 --directory life-deck`，浏览器访问 http://127.0.0.1:8796 。也可直接打开 index.html，资源均为相对路径、经典脚本。

## 验证

在工作区根目录运行：

- `node --test life-deck/tests/*.test.cjs`
- `node life-deck/tests/browser.cjs`（先启动本地服务；复用已安装的 Playwright）
- `python3 life-deck/scripts/package_xhs.py`

浏览器测试覆盖：求职与网站运营隔离、工作情况调整、完整适用前提确认/拒绝、点选自动收集、底部牌组二次阅读、阶段目标的前三组命中与跨领域选择、费用收益原文标签、左划与键盘换牌、快速连点、10 张上限与移除补齐、刷新与旧存档、完整阅读和自动保存估算、原生相册桥模拟、全部 608 个题面在窄屏上的排版与离线加载。桥模拟不代替真机验收。
