# 人生阶段与完整建议阅读

用户要求以游戏入口开始，先选择人生阶段；建议牌正面放完整问题，翻开后阅读完整建议。画面风格继续待定，不使用写实图。

视觉暂用已有中性色、纸面与牌背；内容顺序为游戏入口、人生阶段、三次追问、问题牌、完整阅读页。动效保留开场发牌、选牌翻面、阅读纸张展开，并支持减少动态效果。

## 路由

四问顺序：人生阶段 → 想找到的答案 → 方向 → 具体处境。每问三选一。

阶段为「刚开启独立生活／正在站稳脚跟／走到新的路口」，按当下处境而非年龄划分。阶段改变下一问文案、目标顺序及部分处境顺序；最终具体方向、处境决定同组的三条建议。不会以某个阶段为由排除照护、转行等其他选择。这是首版编辑规则，未验证为画像量表。

## 内容不再压缩

- 81 张牌逐一编写完整问题，不使用文本省略或行数截断。
- 点击问题牌翻面后，直接展开全页阅读，不先弹出适配追问。
- 相关原文以完整三级标题小节切片显示，保留成本、正文、收益、来源、作者分级及备注；不再要求另点出处才能读到这些内容。
- 阅读页明确区分原文相关建议、背景参考和产品整理。13 张产品整理卡没有直接匹配原文，明确说明，不补造出处。
- 产品行动步骤仍完整呈现。相关章节全文保留为额外查阅入口。
- 页面自然滚动、正文可以选择，无内嵌小阅读窗或省略号。

## 保存

收藏保留整张卡的行动数据，以稳定卡片 ID 关联包内原文。旧 v1 收藏及完成状态、估算保留，旧回答因缺少人生阶段重新开始。

每张阅读页可导出完整正文与行动的分页图片，1080×1560，按内容换页，不裁掉尾部。小红书内逐页主动保存；浏览器仅展示图片。牌组整体导出仍是行动清单，界面明确与完整阅读页区分。
